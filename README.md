# Bark & Ambrosia Beetle Gallery: landing page redesign (concept)

> A personal UI exploration, built on my fork of the [Bark & Ambrosia Beetle Gallery](https://github.com/ChristopherMarais/barkandambrosiagallery), an open-source image database from the University of Florida Forest Entomology Lab. **This is not the official site, and nothing here has been merged upstream.** It is a reference for how the front page could feel.

## The idea

The home page was a plain white page with a row of cards. Bark and ambrosia beetles live in trees, so I wanted the front door to feel like walking through a pine forest and meeting one of them: deep green, layered trees drifting past, light coming through the canopy, and a beetle that notices you.

## What's in it

- **A beetle that follows your cursor.** It turns to face wherever your mouse is, looks down at you when the cursor is on top of it, flips over to show its belly when you click it, and slowly turns on the spot when you leave it alone.
- **A forest.** Three layers of pines and ferns slide past at different speeds, with light rays, drifting mist and fireflies.
- **Real specimens from the database.** The hero panel features identified specimens that have a photo (one per genus, cached for ten minutes) with the species name, authority, ranks, the photographer's credit and an "Explore *genus*" link.
- **A headline that never gets covered.** "BEETLES" and the welcome line are sized to the room left of the specimen panel, so nothing overlaps on a small laptop or a large monitor (checked from 1100 px to 2560 px wide).
- **Coloured shadows per tab.** Each sidebar tab and each home card has its own colour for its shadow, glow and icon. The sidebar is dark green on every page.
- **Accessible by default.** People who ask their system for reduced motion get a still page; the carousel works with the arrow keys and swipe; the decorative layers are hidden from screen readers.

## How it works

- **The beetle** is a 12-view sprite sheet (4 x 3). The cursor's direction from the beetle is turned into one of eight compass sectors (with a few degrees of hysteresis so it doesn't flicker on a boundary), each mapped to the view that faces that way. Two stacked layers cross-fade between views. To make the sheet I traced each beetle as its own connected shape with Pillow and numpy, because the beetles overlapped the grid lines, then centred every frame on the beetle's body so it doesn't jitter as it turns.
- **The forest** is three seamless SVG tiles generated by a seeded script. Each strip is a pseudo-element that slides exactly one tile width and repeats, so the loop never shows a join.
- **The layout** uses CSS `min()` and `calc()` to size the headline to the space beside the panel, so it adapts to any window instead of being tuned to one.
- **Fresh files while developing:** a small template tag adds a `?v=<modified time>` to the new stylesheets and scripts only when `DEBUG` is on, so an edited file is never served stale from the browser cache.
- **Tests** cover the featured-specimen selection, the layout hooks, the sprite sheet and the cache tag. Page tests also now use their own in-memory cache, so running them no longer overwrites the cached numbers of a running app.

## Quick Start

```bash
git clone https://github.com/ChristopherMarais/barkandambrosiagallery.git
cd barkandambrosiagallery
echo DJANGO_DEBUG=True > .env
docker compose build
docker compose run --rm web pixi run install-js
docker compose up -d --wait db
docker compose exec db psql -U beetles_user -d beetles_db -c "CREATE EXTENSION IF NOT EXISTS pg_trgm;"
docker compose run --rm web pixi run migrate
docker compose run --rm web pixi run python manage.py createsuperuser
docker compose up -d
```

Then open [http://localhost:8000](http://localhost:8000). See [Getting Started](https://github.com/ChristopherMarais/barkandambrosiagallery/wiki/Getting-Started) in the wiki for the full walkthrough and the daily dev loop.
